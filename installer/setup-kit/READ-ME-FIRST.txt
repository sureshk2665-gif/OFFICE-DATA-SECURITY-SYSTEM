OFFICE COMPUTER SECURITY - SETUP KIT
====================================

This folder makes ONE setup program, OfficeSecurity-Setup.exe, for all office computers.

A) MAKE THE SETUP PROGRAM (once)
   1. Right-click the downloaded zip file > "Extract All..." > Extract.
   2. In the extracted folder, double-click MAKE-SETUP.bat.
      (If Windows shows "Windows protected your PC", click "More info" > "Run anyway".)
   3. After 1-3 minutes it shows DONE, and OfficeSecurity-Setup.exe is in this folder.
   It uses the C# compiler that is part of Windows (.NET Framework 4.8). Nothing is downloaded.
   (A ready-made OfficeSecurity-Setup.exe is also available from the same build, under
   the artifact "OfficeSecurity-Setup".)

B) MAIN OFFICE COMPUTER (do this first, on ONE computer that stays switched on)
   1. Double-click OfficeSecurity-Setup.exe and click Yes when Windows asks for permission.
   2. Welcome > Next > choose "Main office computer" > Install.
   3. The Finish page shows the FIRST ADMINISTRATOR SETUP CODE, the address for staff
      computers and the PAIRING CODE (also saved in C:\ProgramData\OfficeSecurity\Server\).
      Keep "Open Office Security now" ticked and click Finish.
   4. Choose "Administrator sign-in". The server address and pairing code are already
      filled in: click Connect, create the first administrator with the setup code, and set
      up your authenticator app.
   The server runs in the background as a Windows service (no window) and starts with Windows.
   If you started OfficeSecurity.Server.exe by hand before, setup closes it and keeps its data.

C) EACH STAFF COMPUTER
   1. On the main office computer: Office Security > Administrator sign-in > Computers >
      "Add computer". Note the server address, pairing code and enrollment code (24 hours).
   2. On the staff computer, double-click OfficeSecurity-Setup.exe > Yes > Next >
      "Staff computer" > Next, type the three values > Install > Finish.
      (A mistyped code is reported on the last page: click Back and correct it.)
   3. On the main office computer: Computers > select the new computer > Approve.
   4. Staff open "Office Security" on the desktop > "Staff sign-in".

   The Administrator sign-in and the Staff sign-in are completely separate: separate
   accounts, separate screens. Staff computers only show the Staff sign-in.

D) UPDATING
   Run a newer OfficeSecurity-Setup.exe: it recognises the installed version and offers Install. The main office computer keeps all
   its data; staff computers keep their registration (no new codes needed).

E) REMOVING
   Windows Settings > Apps > "Office Computer Security" > Uninstall.
   - Staff computer: needs the uninstall code from the dashboard
     (Computers > select the computer > Uninstall code). Without it nothing is removed.
   - Main office computer: the server is removed, but its data is kept in
     C:\ProgramData\OfficeSecurity\Server (delete it yourself only if you are sure).

What is inside: files\App\OfficeSecurity.exe (the combined program), files\Server\
(the central server), files\Agent\ (the security agent), files\install.ps1 (the setup
steps, readable text) and files\setup-program\ (the source of the small setup program that
unpacks the files and runs install.ps1). No passwords or keys are included.
