OFFICE COMPUTER SECURITY SYSTEM - DEVELOPMENT BUILD (PHASE 3)
==============================================================

IMPORTANT: This build does NOT block anything yet. USB, software and file
protection are switched on in Phase 5. Phase 3 connects office computers:
you can see every computer, its status, hardware, connected USB/phone/
Bluetooth devices and events, and send it security policies.
Use it on test computers only.

Folders in this package
  Server\          OfficeSecurity.Server.exe          Central server (one office PC)
  AdminDashboard\  OfficeSecurity.AdminDashboard.exe  Administrator program
  StaffApp\        OfficeSecurity.StaffApp.exe        Staff program
  Agent\           OfficeSecurity.Agent.exe           Security agent (install on every office PC)

You will need: a smartphone with an authenticator app
(Microsoft Authenticator or Google Authenticator, both free).

STEP 1 - Start the server (on the PC that will be the office server)
  Right-click Server\OfficeSecurity.Server.exe and choose "Run as administrator".
  A black window opens. Leave it open. It shows:
    - the server addresses, for example https://192.168.1.20:5443
    - a PAIRING CODE, for example 6162-C295-C5AF-BC9A-60DD
    - a FIRST ADMINISTRATOR SETUP CODE, for example K7QM-2XRP-9FTA
  The same information is saved in C:\ProgramData\OfficeSecurity\Server\
  (SERVER-CONNECTION-INFO.txt and FIRST-ADMIN-SETUP-CODE.txt).
  If Windows Firewall asks, allow access on "Private networks" so other office PCs can connect.

STEP 2 - Connect the administrator dashboard
  Start AdminDashboard\OfficeSecurity.AdminDashboard.exe (on the server PC or another office PC).
  Type the server address (for example 192.168.1.20) and the pairing code, then click Connect.
  The pairing code proves the dashboard is talking to YOUR server.

STEP 3 - Create the first administrator
  Enter the first administrator setup code, choose a user name, your name and a password
  (at least 12 characters; a short sentence such as "Blue tractor at noon" works well).
  Scan the QR code with your authenticator app and type the 6-digit code it shows.
  Then sign in with your user name, password and the current 6-digit code.

STEP 4 - Add a staff member
  Open "Staff Accounts" and click "Add staff member". Enter an employee code (for example EMP001)
  and a name. The dashboard shows a one-time SETUP CODE. Give it to the staff member.
  (You never see or choose their password.)

STEP 5 - Staff first sign-in
  On a staff PC, start StaffApp\OfficeSecurity.StaffApp.exe and connect with the server address
  and pairing code (a one-time step for each PC).
  Click "First sign-in", enter the employee code, the setup code and a new password.

STEP 6 - Add an office computer (the security agent)
  In the dashboard open "Computers" and click "Add computer". It shows a command with
  a one-time enrollment code (valid 24 hours).
  On the office computer:
    a) Copy the Agent folder to it (USB stick or network share).
    b) Click Start, type "cmd", right-click Command Prompt, choose "Run as administrator".
    c) Go to the Agent folder (for example: cd C:\Users\you\Desktop\Agent)
    d) Paste the command from the dashboard and press Enter.
       It checks the server, installs the "Office Security Agent" service and registers.
  Back in the dashboard (Computers): the computer shows "PendingApproval".
  Select it and click "Approve". Within a minute it shows as Online with its details.
  The agent starts automatically with Windows and restarts itself if it is stopped.
  Staff (standard Windows users) cannot stop it.

STEP 7 - Staff on that computer
  Start StaffApp\OfficeSecurity.StaffApp.exe on the approved computer: it connects
  automatically through the agent (no pairing needed).
  To restrict a staff member to certain computers: Computers -> select the computer ->
  tick the staff member under "Staff allowed to sign in on this computer" -> Save.

STEP 8 - Security policies (what is blocked)
  "Security Policies": edit the default policy or create others and assign them to
  computers (Computers -> Security policy). Computers apply a changed policy within
  a minute of their next check-in. Available now:
    - USB drives and memory cards: Off / Audit (record only) / Enforce (block).
      Optionally also phones and cameras (file transfer) and CD/DVD drives.
      Keyboards, mice and printers keep working. A drive that is already plugged in
      must be unplugged and plugged in again.
    - Stop staff installing programs for themselves.
    - Blocked websites and no private browsing (Edge, Chrome, Firefox).
    - Programs without network access (full path of the program).
    - Programs staff bring in (Application Control, Windows 11 22H2 or later):
      only Windows, Microsoft programs and programs installed in Program Files may run.
      ALWAYS use "Audit" for a few days first: "Security Events" then lists every
      program that WOULD be blocked. Install needed programs properly (per-machine,
      in Program Files) before choosing "Enforce". On such computers put the staff
      app in C:\Program Files\OfficeSecurity\StaffApp.
    - Record Windows sign-ins (who signed in, failed sign-ins, sign-outs).
    - Company folders: record who opens, changes or deletes files there, and
      ransomware protection (needs Microsoft Defender as the antivirus).
    - Require BitLocker: each computer reports whether its drives are encrypted
      (it does not switch BitLocker on for you). The recovery keys of encrypted
      drives are sent to the server and stored encrypted. On the computer's page,
      "BitLocker recovery keys" -> "Show selected recovery key" (super administrators
      only; every time is recorded in the audit log).
    - Approved USB drives: while USB drives are blocked (Enforce), company drives can
      still be used. Plug the drive into an approved computer once, open that computer's
      page, select the drive (type DiskDrive) in the device list, type a description
      and click "Approve this USB drive". It then works on every computer using that
      policy; other USB drives stay blocked. Programs can never be run from a USB drive.
      Remove approvals in "Security Policies" (list "Approved USB drives").
    - Allowed Wi-Fi networks: only these networks can be joined (stops phone hotspots).
      SAFETY RULE: a computer connected to a network NOT on the list does not apply the
      restriction (so it is never cut off) and reports this - add that network first.
      Cable (wired) network is not affected.
    - Bluetooth: "BlockFileTransfer" stops sending files over Bluetooth (needs Application
      Control on Enforce); keyboards, mice and headsets keep working. "DisableRadio"
      switches Bluetooth off completely, including wireless keyboards and headsets.
  Items marked "not available yet" are saved but have no effect.
  TIP: create a test policy, assign it to ONE computer, check it for a day, then use it
  for everyone. Use "Audit" first for USB drives to see who uses them.
  On each computer's page, "Security protections" shows what Windows has actually
  applied ("On (verified)"). If anyone changes a protection by hand, the agent puts it
  back within a minute and you see a Critical "PolicyTamperAttempt" event.
  Temporary exception: on a computer's page, "Temporary exceptions" lets you allow, for
  example, USB drives on that one computer for 1 hour. It switches back on by itself.

STEP 8b - Events
  "Security Events": everything the computers report. "USB connection log" shows USB
  drives, phones and Bluetooth devices being connected.

STEP 9 - Software: approved list, installers, requests
  "Software Management":
    - "Programs found on approved computers" lists every program the computers report
      (as in Windows "Installed apps"). Tick "Only programs not on the approved list" to
      see what staff installed without approval. Nothing is removed or blocked yet (Phase 5).
    - "Add program" puts a program on the approved list (name as shown in Installed apps;
      the start of the name is enough).
    - Select a program, click "Upload installer..." and choose its .msi or .exe file.
      Download installers only from the publisher's official website. The dashboard
      shows who signed the file. For .exe files enter the silent install options from the
      publisher's documentation (often /S or /quiet).
    - Select the uploaded installer and click "Install on computers...". Each computer
      checks the file's fingerprint and signature before installing it silently.
      Progress is shown under "Installations".
  Staff ask for software in the staff app ("Request software"). You decide under
  "Installation Requests": choose the installer and click "Approve and install", or
  "Reject" with a note. The staff member sees the result in "My requests".

STEP 10 - Look at the audit log
  In the dashboard open "Audit Logs". Every sign-in, failed sign-in and account change is listed.
  Click "Verify integrity" to check that nobody has altered the log.

Removing the agent from a computer (administrator Command Prompt):
  "C:\Program Files\OfficeSecurity\Agent\OfficeSecurity.Agent.exe" uninstall
  This also removes every protection the agent set (USB, websites, firewall rules...).
  Then remove the computer in the dashboard (Computers -> Remove from management).
Checking the agent on a computer:  ...\OfficeSecurity.Agent.exe status

PILOT CHECKLIST - try the protections on ONE test computer first (not a production PC)
  1. Assign a test policy with the protection switched on and wait 2 minutes.
  2. On that computer open an administrator Command Prompt and run:
       "C:\Program Files\OfficeSecurity\Agent\OfficeSecurity.Agent.exe" check
     It tests, on that computer, what the policy asks for and prints a line per check:
     ✓ = working as the policy says, ✗ = problem. It is safe: it only reads.
  3. Try it for real, with the check command after each step:
     - plug in a personal USB drive  -> it must NOT open (✓ "cannot be read")
     - plug in an approved USB drive -> it must open
     - connect a phone               -> no files visible (charging works)
     - try to join a phone hotspot   -> not listed (if Wi-Fi networks are restricted)
     - send a file over Bluetooth    -> refused (if Bluetooth file transfer is blocked)
  4. Check the dashboard: the computer's "Security protections" and "Security Events".
  5. Only then assign the policy to other computers.

Good to know
  - 5 wrong attempts lock an account for 15 minutes.
  - Forgot a staff password? Select the staff member and click "Issue new setup code".
  - Lost your phone? Another super administrator can reset your account. Create a second
    super administrator under "Administrators" so you are never locked out.
  - Back up the whole folder C:\ProgramData\OfficeSecurity\Server regularly.
    It holds the database and the keys.

Windows SmartScreen may say "Windows protected your PC", because development builds are not
code-signed yet. Click "More info" and then "Run anyway" (test PCs only).
